# Sistem-panen-Kel.4
Sistem Panen merupakan program Python sederhana yang digunakan untuk menghitung dan menampilkan hasil perhitungan penjualan hasil panen berdasarkan jumlah hasil panen dan harga per kilogram.

## Fitur

- Input data hasil panen
- Perhitungan total hasil penjualan
- Perhitungan diskon
- Menampilkan laporan hasil panen

## Cara Menjalankan Program

1. Pastikan Python sudah terinstal pada komputer.
2. Clone repositori ini ke komputer.
3. Buka folder `sistem-panen`.
4. Jalankan program dengan perintah:

```bash
python panen.py
